# PROG101_ASSIGNMENT1_MARIATU_MAY_KUTHOLIKO_KAMARA_905006572
ogical design for PowerWise SL, a prepaid electricity units planner for Sierra Leone households. It calculates each appliance's daily kWh, finds the biggest consumer, predicts how many days the units will last, and warns when they'll run out within a week. Includes the algorithm, pseudocode and flowcharts. Supports SDG 7. PROG101 assignment.
# PROJECT BACKGROUND
Most households in Sierra Leone use EDSA prepaid meters, but they cannot tell how long their units will last or which appliances use the most power, so they often run out without warning. PowerWise SL calculates each appliance's daily use, predicts how many days the units will last, and warns the household before they run out. It supports SDG 7, Affordable and Clean Energy.
# HOW THE SYSTEM WORKS
1. Enter the number of appliances (1 to 20).
2. For each appliance, enter its name, wattage and hours used per day.
3. The system checks the inputs and asks again if any are invalid.
4. It calculates each appliance's daily use: kWh = (watts × hours) ÷ 1000.
5. It rates each appliance as High, Medium or Low.
6. It adds up the total daily use and finds the biggest consumer.
7. Enter the units bought.
8. The system calculates how many days the units will last.
9. If the units will run out in under 7 days, it shows a warning and names the biggest consumer. Otherwise, it confirms the units will last more than a week.
